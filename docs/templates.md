# 可选记录骨架

这些是给 agent 的提示，不是用户要填写的表单。只保留有内容的字段；占位符不得作为真实记录提交。

## 通用笔记

```markdown
# 标题

创建：YYYY-MM-DD · 更新：YYYY-MM-DD
类型：想法 / 理解 / 解题 · 状态：萌芽 / 探索中 / 未验证 / 已验证
别名：按需填写

## 核心内容
忠实整理用户的表述，明确主观理解与已核实事实。

## 疑问与边界
保留未确定之处；没有则省略。

## 演变
有重要修正时记录日期、之前怎么想、为什么改变。

## 来源与关联
链接原话、资料以及相关笔记。
```

想法可用“起因 / 想探索什么 / 未想清楚的部分”。知识可用“我的理解 / 我的例子 / 不理解的地方 / agent 补充（如有）”。解题可用“题目与约束 / 我的尝试 / 卡点与失败原因 / 关键转折 / 当前解法 / 验证情况”。不要为了套模板删除不适配的内容。

## 原始证据

```markdown
# 资料标题

- 来源类型：用户对话 / 网页 / 文档 / 附件
- 记录日期：YYYY-MM-DD；时区：实际采用的时区
- 提供者 / 作者：已知信息
- 定位：可获得的 URL、消息标识、页码或会话说明
- 保存范围：相关原话摘录 / 完整原件 / 仅链接

## 原文
原样保存；不得用摘要伪装原文。
```
