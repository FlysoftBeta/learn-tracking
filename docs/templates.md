# 可选记录骨架

给 agent 的参考，不让用户填表。只保留真实有用内容，不提交占位符。

## Journal 事件

- 小节标题：事件或主题。
- 语义记录：用户报告、理解、决定了什么；必要时说明实质变化和原因。
- 关联：相关任务 ID、主题页；需要时链接原件。

先修复明显表达错误，再记录含义。不单列 typo 修复，不复制整段对话。

## 主题笔记

- 标题：未来会检索的问题或主题。
- 当前内容：有效理解、需求、方法或想法。
- 边界：真正未解决的问题、验证范围。
- 来源：对应 journal 小节，必要时附原件。

想法可写动机和疑问；知识可写模型、例子与边界；解题可写推导、关键失败原因与验证。不要默认生成“演变”“澄清”“agent 整理说明”等章节。只有解释当前内容所必需的实质变化才进入正文。

## 原始资料（按需）

记录标题、提供者或作者、获取日期、实际出处、保存范围及原件。逐字引文保持原样，语义摘要不能冒充原文。附件的提取文本与原件分开保存。
