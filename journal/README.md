# 每日记录

journal 是 chronological truth：按事件顺序记录用户当时报告了什么、如何理解、作了什么决定及后续实质变化。用户报告与外部验证需要区分。

路径为 YYYY/MM/YYYY-MM-DD.md，仅在有值得记录的事件时创建。按事件日期放置，补记时另注记录日期；同日用有意义的小节和出现顺序，不虚构具体时间。

先理解语义再简洁记事，自动修复明显 typo 和重复。这里也不保存逐轮聊天噪声或工具操作流水账。实质修正追加新事件；表达修复直接改正文，不单列“纠错事件”。

任务事件引用 [TASKS.md](../TASKS.md) 中的稳定 ID，当前状态只在那里维护。可复用内容物化为 notes，用小节链接关联；需要逐字核对时再指向 sources。默认不为每次输入复制原话文件。
