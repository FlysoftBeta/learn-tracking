# 英语学习

## 对当前英语课的判断

用户认为当前英语课的价值较低。核心问题不是泛泛的课堂体验，而是它无法直接介入做题反馈循环：出错后不能及时追踪错误、重现具体场景并提供针对性反馈，所提供的内容因而难以帮助改进。

## 高考英语写作 workflow / suite 构想

初步方向是设计一套完整、切面较小的写作训练 workflow / suite，围绕可直接用于写作与反馈的素材组织，而不是铺开成宽泛课程。

读后续写可覆盖：

- 常用叙事结构；
- 常用语段；
- 人物情感描写语段；
- 主旨选定；
- 情节设计。

应用文写作可覆盖：

- 中国政策与社会热点的英语表达；
- 常见观点的恰当英语表达。

当前仍是初步构想，尚未确定具体实现形式、训练流程或任务安排。

应用文已确定从单个专题而非整篇作文起步。选题参考课标主题语境，并吸收近期社会趋势与国家政策作为现实背景；不要求所有主题都作价值升华。首批候选见[应用文主题素材池](英语/应用文主题素材池.md)。
