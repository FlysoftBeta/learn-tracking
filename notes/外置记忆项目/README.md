# 外置记忆项目

本仓库是个人外置记忆系统，用于维护待办、长期想法、知识理解和解题思路。

## 范围

本主题管理记录工作流、信息架构、检索与上下文质量。学习 app 的功能、前端、布局与交互需求归 [学习app](../学习app/README.md)，两个项目独立维护。

## 项目入口

- [信息架构](../../docs/architecture.md)：journal 时间事实、notes 当前视图、索引及原始资料的职责。
- [Agent 工作流](../../AGENTS.md)：语义理解、记录、检索、整理与 Git 同步。
- [记录偏好](../../PREFERENCES.md)：用户明确表达的维护要求。
