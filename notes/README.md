# 想法与知识

按用途放置，主题通过 [主题地图](../index/topics.md) 跨目录关联。目录按第一次实际记录创建，不预设学科分类。

- `ideas/`：还没成形的想法、动机、可能性、悬而未决的问题。
- `knowledge/`：我如何理解一个概念，例子、边界、疑惑和理解演变。
- `problems/`：问题上下文、尝试路径、失败原因、关键洞察与验证情况。

文件名使用简短可搜索标题，例如 `knowledge/递归与调用栈.md`。一篇围绕一个可独立检索的问题；短小的相关碎片可先共存，不强制原子化。标题变化不必改文件名。

每篇至少包含标题、创建/更新日期、类型或状态、来源，以及实际正文。别名、关联和演变只在有内容时增加。没有验证的解法标注“未验证”，不要把猜测写成结论。
