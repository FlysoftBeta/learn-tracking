# 想法与知识

这里保存面向检索的当前主题视图，由 [每日记录](../journal/README.md) 中的有效信息物化而来。以未来要回答的问题组织正文，不复述聊天过程。

- 想法：动机、可能性、值得继续探索的问题；不要求已经成形。
- 知识：自己的理解、例子、边界和有解释价值的认知转折。
- 解题：题意、推导、关键洞察、值得复用的失败经验及验证情况。
- 项目：当前目标、进度概况、需求和约束；任务状态链接 TASKS。

优先更新已有主题。每段必须有持久用途；修正 typo、去重、删除已解决的措辞疑问，不建立纠错历史。实质历史留在 journal，正文通过少量链接溯源。按需使用 ideas/、knowledge/、problems/ 或现有主题目录，不强制重排。

每篇保留清楚的标题、当前内容和来源链接；日期、状态、别名等元信息只在有用时添加。agent 推论和未验证内容不得冒充用户事实。
