# 我的外置记忆

直接把想记的内容告诉 agent，分类、关联、保存和同步由 agent 完成。不需要先整理好，也不需要填写模板。

- [待办](TASKS.md)：所有事项的唯一状态来源。
- [每日记录](journal/README.md)：今天做了什么、为什么、当时怎么想。
- [想法与知识](notes/README.md)：长期想法、自己的理解、解题过程。
- [主题地图](index/topics.md)：按概念、别名和关联找回记忆。
- [原始资料](sources/README.md)：按需保留的原件、附件及提取文本。

可以直接说：“记一下……”“今天要做……”“我对递归的理解是……”“这题我试过……”“找找我以前怎么想的”“整理最近的记录”。未成形的想法也值得保存，没有截止时间就不添加截止时间。

记录后，agent 立即提交并推送，回复保存位置和同步结果。仅查询不会制造新记录。个人时区未指定时按当前环境时区处理日期。

使用 Markdown、相对链接和 Git。journal 保存按时间组织的语义事实，notes 提炼当前有效内容，索引负责发现，原始资料按需核对。明显笔误直接纠正，不把措辞修补写进长期笔记。先保持简单，内容实际增长后再拆分。

Agent 从 [AGENTS.md](AGENTS.md) 开始；详细约定见 [信息架构](docs/architecture.md)，可选骨架见 [模板](docs/templates.md)，明确偏好见 [PREFERENCES.md](PREFERENCES.md)。
