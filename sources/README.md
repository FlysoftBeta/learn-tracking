# 原始证据与资料

目录：`YYYY/MM/YYYY-MM-DD-NNN-短标题.md`。同一天的序号递增，创建前检查重名。附件放同名资料目录，原文件名与原始 URL 写入说明。

每份证据写明：来源类型、记录时间及已知时区、事件时间（若不同且已知）、作者或提供者、原文/摘录、定位信息。没有消息 ID 时用会话日期和摘录定位，绝不编造 ID。只有日期就只写日期，不虚构时间精度。

- 用户口述：原样保留与记忆有关的片段，标记为摘录；整理后的表述放 notes 或 journal。
- 网页或文档：记录标题、作者（已知时）、URL、获取日期及实际保存范围。仅保存了链接就标明“仅链接，未获取正文”。不得把未读来源写成已核实。
- 附件：保留原件；OCR、转录和文本提取另存 `*.extracted.md`，链接原件并说明方法和可能的识别错误。
- 派生笔记：链接证据文件的具体小节或页码。只在资料有明确用途时摘要、结构化、关联，不为收藏而复制全库。

原始证据默认追加保存，不静默改写原文。错误用更正说明或新证据纠正。用户明确要求删除或隐私清理时执行相应范围，并注意普通 Git 删除不会移除历史版本。不要提交密钥、认证信息或无关敏感内容。
